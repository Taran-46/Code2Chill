# AGENTS.md — Repository-wide agent entry point

This repository is the Code2Chill official club website.

Before working:
1. Read `PROJECT.md`.
2. Read `AI_RULES.md`.
3. Read `DECISIONS.md`, `FEATURES.md`, `TASKS.md`.
4. Read the relevant design/technical documents for the task.
5. Inspect the current implementation before editing.

Follow `AI_RULES.md` as the canonical cross-agent instruction set. Do not invent club facts or silently change approved decisions. Work in small stages, test changes, and update the project documentation.
