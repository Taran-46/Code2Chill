# TECH_STACK.md

## Approved direction
- Next.js App Router: routing, rendering and server-side application functionality.
- TypeScript: static typing.
- Tailwind CSS: styling and responsive utilities.
- shadcn/ui: accessible component foundations where appropriate.
- Motion: purposeful animation.
- Lucide React: icon set.
- Supabase: PostgreSQL, authentication and object storage.
- Zod: runtime validation.
- React Hook Form: forms where complexity warrants it.
- Vercel: deployment.
- GitHub: source control and collaboration.

## Rules
- Select stable, mutually compatible versions at project initialization.
- Commit the lockfile.
- Do not mix package managers.
- Do not add a second database or authentication provider without approval.
- Avoid libraries that duplicate existing framework functionality.
- Document any new dependency and why it is necessary.
- Keep secrets in environment variables.
