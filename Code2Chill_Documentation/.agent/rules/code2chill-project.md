# Code2Chill project rule

Follow the repository's `AI_RULES.md` as the canonical coding-agent policy.

Before implementation, read `PROJECT.md`, `DECISIONS.md`, `FEATURES.md`, `TASKS.md` and task-relevant documentation. Inspect the current code before editing.
